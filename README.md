## 📌 Projects I'm proud of

### 🏙️ Janus Urbanis — City Branding Situation Awareness Platform
Microservices-based platform integrating OSINT data, thematic maps, and environmental data. Advanced ETL pipelines + Computational Intelligence (Fuzzy Logic, Rough Sets) + LLMs for sentiment analysis → dynamic geospatial insights for urban decision-making.

### 🔁 Peerflow — Distributed Peer-Review Platform
Built in 10 days with my project team: scalable microservices, full CI/CD pipeline via Jenkins + Git Hooks, deployed on Docker + Kubernetes (MicroK8s).

### ⚡ Parallel Bellman-Ford
CUDA, OpenMP & MPI implementations — Pure CUDA achieved **~40x speedup** on graphs with |V| = 2.5M nodes.

### 🏓 Robotic Table Tennis Player
Decoupled robotic control into Inverse Kinematics (Supervised Learning, MSE ≈ 3.4e-6) and game strategy (DQN agent with custom reward functions). Outperformed all baseline models.

### 🗺️ Geospatial NoSQL Benchmark
ETL on ISTAT + OpenStreetMap data. GeoJSON indexing achieved **~32x query speedup**; Neo4j outperformed MongoDB **~16x** on complex population aggregations.
